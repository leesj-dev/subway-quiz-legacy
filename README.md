# 지하철 노선도 퀴즈

수도권·부산 도시철도 노선도를 보고 역 이름을 맞히는 퀴즈. 혼자서도, 둘이서도.

노선을 먼저 고른 뒤 그 노선에 속한 역 이름을 입력합니다. 맞히면 노선도 위에 역명이 드러나고,
호선별 진행도가 함께 올라갑니다.

## 개발

```bash
npm install
npm run dev
```

멀티플레이를 쓰려면 `.env.example`을 `.env.local`로 복사하고 Supabase 값을 채웁니다.
두 값이 없으면 앱은 그대로 뜨고 싱글플레이만 열립니다.

```bash
cp .env.example .env.local
```

Supabase 프로젝트에는 `supabase/migrations/0001_rooms.sql`을 한 번 적용하면 됩니다.

배포는 Vercel. 별도 설정 없이 `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`
환경변수만 넣으면 됩니다.

## 게임 방식

### 싱글플레이

제한시간 안에 최대한 많은 역을 맞힙니다. 최고기록은 브라우저에 저장되며,
`(지역, 켠 호선, 제한시간)`이 같은 판끼리만 비교합니다.

### 멀티플레이

로그인 없이 6자리 알파벳 코드로 방을 만들고 참가합니다.

- **땅따먹기** — 같은 노선도를 두고 먼저 입력한 사람이 그 역을 차지합니다.
  차지한 역은 그 사람 색으로 칠해집니다.
- **대결** — 각자 노선도를 채우고 제한시간 안에 더 많이 맞힌 사람이 이깁니다.

방장이 방식과 판 설정(지역 · 호선 · 제한시간 · 역 눈금)을 정하고 시작합니다.
시작 신호 뒤 3초를 두고 동시에 출발하므로, 노선도 로딩 시간이 승부에 영향을 주지 않습니다.

### 설정

판 설정은 시작 전에만 정할 수 있습니다.

| 설정 | 설명 |
| --- | --- |
| 지역 | 수도권(655역) / 부산(147역) |
| 호선 | 켜고 끌 수 있습니다. 끈 호선의 역은 출제되지 않습니다. 기본값은 전부 켜기 |
| 제한시간 | 수도권 1~99분, 부산 1~60분 |
| 역 눈금 표시 | 역 위치를 알려 주는 표식 |

아래 세 가지는 점수와 무관해서 게임 중에도 바꿀 수 있습니다.

| 설정 | 설명 |
| --- | --- |
| 투명도 | 노선을 골랐을 때 나머지 노선이 얼마나 물러날지 |
| 환승역 타 노선 색 표시 | 환승역 심볼에서 다른 호선 색도 살릴지 |
| 노선 클릭 시 확대 | 노선을 고르면 그 노선만 확대해 볼지 |

### 입력 요령

- 가운뎃점(·)은 생략하거나 온점(.)으로 대신할 수 있습니다. (`경성대부경대`, `경성대.부경대`)
- 총신대입구는 이수로 인정합니다.
- 노선도는 드래그·휠·핀치로 움직이고 확대할 수 있습니다.

## 구조

```
src/
  app/                 화면 전환을 관장하는 단일 페이지
  components/
    GameScreen.tsx     게임 진행 화면 (노선도 · 노선 버튼 · 입력 · 진행도)
    SetupPanel.tsx     싱글/멀티가 공유하는 판 설정
    screens/           처음 화면 · 멀티 입구 · 대기실
    ui/                shadcn 스타일 프리미티브
  lib/
    mapEngine.ts       노선도 SVG 조작 (강조 · 확대 · 정답 표시). React를 모른다
    regions.ts         지역별 메타와 입력 해석
    room.ts            멀티플레이 API
    useRoom.ts         방 상태 실시간 구독
    data/generated.ts  스크립트가 만드는 정적 데이터 — 직접 고치지 않습니다
public/maps/           노선도 SVG
assets/circles/        노선 심볼 원본
scripts/               노선도 전처리 (한 번 돌리고 결과를 커밋)
supabase/migrations/   멀티플레이 스키마
```

두 노선도는 같은 class 규약을 씁니다. 부산 노선도는 원본이 id 기반이라
`scripts/normalize_busan_svg.py`가 이 규약으로 맞춰 놓았습니다.

| class | 뜻 |
| --- | --- |
| `.line <호선>` | 노선 전체를 감싸는 그룹 (확대할 때 기준) |
| `.mark` | 역 위치를 나타내는 눈금 |
| `.transfer` | 환승역 심볼 그룹 |
| `.fill <호선>` | 환승역 심볼 안의 호선별 색 조각 |
| `.station <호선...>` | 역명 텍스트 (`id` = 역명, 기본 `visibility=hidden`) |

노선도 SVG나 심볼을 고쳤다면 정적 데이터를 다시 만듭니다.

```bash
python3 scripts/gen_map_data.py
```
